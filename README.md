MyPortfolio

📌 **MyPortfolio**, yazılımcıların veya tasarımcıların kendilerini tanıtabileceği, projelerini sergileyebileceği ve deneyimlerini paylaşabileceği işlevsel bir portföy sitesidir. 

🚀 Proje Özellikleri

- Basit ve anlaşılır kullanıcı arayüzü ile kolay kullanım
- Proje ekleme ve güncelleme imkanı
- Çalışma deneyimlerinin ve teknik becerilerin listelenmesi
- Tüm cihazlarla uyumlu, mobil dostu tasarım
- Kişisel bilgiler ve sosyal medya bağlantılarının yer aldığı tanıtım sayfası
- Dinamik içerik yönetimi
- İletişim formu üzerinden mesaj gönderme özelliği

🛠️ Kullanılan Teknolojiler

- **ASP.NET Core (.NET 6)**-
- **C#**
- **Razor Pages**
- **HTML / CSS / JavaScript**
- **SQL Server**
